Bot Engines

Bot games are played against an external Go engine. Engines are separate programs and are not shipped with Tengen, so you have to install at least one supported engine yourself. You can choose between the installed engines in the New Bot Game dialog.

Choosing an Engine

  GNU Go KataGo
Strength Level 1 to 10. These are not ranks: level 10 plays around 5k to 8k, and how much weaker the lower levels play has not been measured. Rank from 20k to 3d.
Style A classic engine. A neural network imitating a human of the chosen rank.
Files One program. One program and three extra files.
Hardware Any computer. A graphics card is recommended.

Setup Guide

Tengen looks for engines in two engine folders, in this order, and takes each engine from the first one that holds all of its files:

  1. Your data folder (recommended):
    • Linux: ~/.local/share/tengen/engine
    • Windows: %LOCALAPPDATA%\tengen\engine
    • macOS: ~/Library/Application Support/tengen/engine
  2. The engine folder next to the Tengen executable.

Inside, each engine has a folder of its own, and the file names must match exactly. On Linux they are case-sensitive. 

engine/
├── gnugo/
│   └── gnugo(.exe)
└── katago/
    ├── katago(.exe)
    ├── model.bin.gz
    ├── human_model.bin.gz
    └── gtp.cfg

An engine missing a file is greyed out in the New Bot Game dialog. The dialog looks again every time it opens, so you can install an engine while Tengen is running.

Setting up GNU Go

Use GNU Go 3.8.

Windows

Download a GNU Go 3.8 build and copy its whole contents into engine\gnugo, not just gnugo.exe. Builds such as the Cygwin one need their .dll files next to the executable.

Linux

Install GNU Go with your package manager, then link it into place:

mkdir -p ~/.local/share/tengen/engine/gnugo
ln -s "$(command -v gnugo)" ~/.local/share/tengen/engine/gnugo/gnugo

Setting up KataGo

Copy KataGo's whole folder into engine/katago, then add three files:

Name What it is Where to get it
model.bin.gz A regular KataGo network. Any network from katagotraining.org, renamed.
human_model.bin.gz The network trained on human games. It imitates the rank. b18c384nbt-humanv0.bin.gz from katagotraining.org's extra networks, renamed.
gtp.cfg KataGo's configuration, made for the human network. KataGo's gtp_human5k_example.cfg, renamed.

The rank comes from the bot dialog. It replaces the humanSLProfile in gtp.cfg, so one config serves every rank.

KataGo is released in builds for different hardware: OpenCL, CUDA, TensorRT and a plain CPU build (Eigen). Pick the one that fits your graphics card. The CPU build runs anywhere but is slow.

Game settings

Bot games are played on 9×9, 13×13 or 19×19 with a komi of 7.5, which is fixed for now. Repeating a position is forbidden, as in the rules of Go.

Troubleshooting

Problem Likely cause and fix
The dialog says No engine is installed. No engine has all of its files yet. See Setup Guide.
An engine I installed is greyed out.
  • A file is missing or named differently, for example model.bin.gz.gz.
  • The files sit one folder too deep, for example engine/gnugo/gnugo-3.8/gnugo.exe.
  • Its files are split between both engine folders. Keep them together in one.
  • On Linux, the link to the engine is broken. A broken link counts as a missing file. ls -L on it shows whether it works.
The engine is listed, but the game ends right after it starts. The engine did not start or did not answer. The engine log shows why. Common causes:
  • Windows: the .dll files GNU Go needs are missing next to gnugo.exe.
  • Linux: the engine is not executable. Run chmod +x on it.
  • KataGo: the build does not match your hardware, for example a CUDA build without an NVIDIA card. Try the OpenCL or Eigen build.
  • KataGo: gtp.cfg is not made for the human network, or a network file is damaged.
The game ends in the middle of play. The engine stopped answering, and Tengen ends a game its opponent cannot continue. The engine log shows why.
KataGo takes a long time to answer. KataGo is probably running on the CPU. Install a build for your graphics card.

Engine log

Each engine writes what it reports to gnugo.log or katago.log. The file is created in the folder Tengen was started from and is overwritten by every new game. When you ask for help, include this file together with the engine version and your operating system.
